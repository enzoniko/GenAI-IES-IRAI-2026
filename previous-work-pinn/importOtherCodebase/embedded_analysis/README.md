# C++ Detection Pipeline Benchmark

This directory contains a C++ implementation designed to benchmark the performance of a Physics-Informed Neural Network (PINN) coupled with an Extreme Value Theory (EVT) based anomaly detection pipeline. The primary goal is to evaluate its suitability for deployment on resource-constrained embedded systems, such as RISC-V platforms.

## Components

The pipeline consists of several key C++ classes:

1.  `NeuralNetwork`: A simple feed-forward neural network implementation used within the PINN.
2.  `PhysicsInformedModel`: Implements the PINN. It takes system state variables as input, uses a neural network (`acc_network`) to predict *normalized* accelerations, and another network (`phys_network`) to estimate unmeasured physical terms. It calculates physics-based residuals, denormalizing the predicted accelerations *internally* before using them in the physics equations.
3.  `FeatureExtractor`: Extracts time-domain, frequency-domain (using FFT), and wavelet-domain features from the residual time series generated by the `PhysicsInformedModel`.
4.  `StandardScaler`: Standardizes features by removing the mean and scaling to unit variance.
5.  `PCA`: Performs Principal Component Analysis for dimensionality reduction on the extracted features.
6.  `EVTAnomalyDetector`: Orchestrates feature extraction, scaling (using `StandardScaler`), PCA transformation, and anomaly scoring. It compares the final score (norm of the PCA-projected features) against a threshold to detect anomalies. PCA is *always* applied in this version.
7.  `DetectionPipeline`: The main orchestrator class. It initializes the `PhysicsInformedModel` and `EVTAnomalyDetector`, generates test data, runs the detection process, and measures execution time.
8.  `wavelet` (External Library): Provides wavelet decomposition functionality used in `FeatureExtractor`. Located in the `wavelet/` subdirectory.

## Building and Running

A `Makefile` is provided for easy compilation and execution.

*   **Build Release Version:**
    ```bash
    make
    # or
    make all
    ```
    This compiles the code with optimizations (`-O2`) and creates the executable `detection_pipeline_test`.

*   **Run Release Benchmark:**
    ```bash
    make run
    ```
    This builds the release version (if necessary) and runs the benchmark (`NUM_RUNS` times, currently 100). It prints the **average execution time (ms)** and the **standard deviation (ms)** separated by a space.

*   **Build Debug Version:**
    ```bash
    make debug-build
    ```
    This cleans previous builds and compiles the code with debug symbols (`-g`) and enables detailed logging (`-DDEBUG_LOGGING`).

*   **Run Debug Benchmark:**
    ```bash
    make run-debug
    ```
    This builds the debug version (if necessary) and runs the benchmark. It prints verbose output from various stages of the pipeline, including individual run times and anomaly results, along with the final average time and standard deviation.

*   **Clean Build Files:**
    ```bash
    make clean
    ```
    This removes the executable (`detection_pipeline_test`) and all generated object files (`*.o`).
