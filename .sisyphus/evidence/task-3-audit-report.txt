Comparison result:
- Coefficients, signs, variables, and mass constraints match the reference implementation.
- Derivative handling inside src/models/pinn.py matches the reference pattern: accelerations and velocities are consumed as inputs; no autograd or finite-difference derivative calculation occurs inside compute_residuals.
- One verified mismatch was found after the residual equations: current src/models/pinn.py divided residual1-4 by 1e6 before returning them, while previous-work-pinn/basicPINNv8.py returns the raw residuals.
- Fix applied: removed the extra 1e6 residual scaling so the current implementation matches the proven reference equations and loss magnitude behavior.
